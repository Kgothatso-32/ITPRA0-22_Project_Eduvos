# ITPRA0-22_Project_Eduvos
Developing a Python-based Learner Management Progress Tracking System that helps staff to capture learner details, record assessment marks, determine learner performance and generate simple progress feedback. 
This project will be developed in Python and will cover variables, input/output, arithmetic operations, decision structures, loops, functions, lists, object-oriented programming, inheritance, encapsulation, recursion, exception handling, and a simple GUI feedback using message boxes.
